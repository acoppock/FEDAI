# Clingingsmith, Khwaja and Kremer (2009) Hajj lottery

958 Pakistani Muslims who applied for Hajj visas allocated by lottery.
Used in Chapter 3.

## Usage

``` r
clingingsmith_khwaja_kremer_2009
```

## Format

A data frame with 958 rows and 2 columns:

- Z_hajj:

  Won the visa lottery and went on the Hajj

- Y_views:

  Index of views toward other Muslim nationalities, from -12 to 12
