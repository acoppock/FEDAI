# Table 8.1 from FEDAI

Hypothetical potential outcomes for three employees depending on who is
honored with an employee of the month award. Each subject has one
potential outcome per possible recipient, which is what interference
means here.

## Usage

``` r
table_8_1
```

## Format

A data frame with 3 rows and 5 columns:

- observation:

  Employee: Mary, Peter or Limor

- Y_Z_Mary:

  Outcome if Mary is honored

- Y_Z_Peter:

  Outcome if Peter is honored

- Y_Z_Limor:

  Outcome if Limor is honored

- Y_Z_Nobody:

  Outcome if no one is honored
