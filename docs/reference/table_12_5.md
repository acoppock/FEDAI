# Table 12.5 from FEDAI

Hypothetical potential outcomes for a tailored-treatment design based on
the Chong, De La O, Karlan and Wantchekon (2011) municipal audit
experiment. The content of treatment depends on the subject's type, so
some cells of the schedule of potential outcomes are never observable.

## Usage

``` r
table_12_5
```

## Format

A data frame with 4 rows and 3 columns:

- type:

  Municipality type, honest or corrupt

- Y_Z_0:

  Turnout under control

- Y_Z_1:

  Turnout under the treatment tailored to that type
