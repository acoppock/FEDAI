# Table 3.5 from FEDAI

The same schedule as Table 3.4, regrouped into three blocks and without
the village identifier.

## Usage

``` r
table_3_5
```

## Format

A data frame with 14 rows and 3 columns:

- Block:

  Block, 1 to 3

- D:

  Treated potential outcome, `"."` where unrevealed

- Y:

  Untreated potential outcome, `"."` where unrevealed

## Source

ISPS Data Archive study D081
[doi:10.60600/YU/VUH8KD](https://doi.org/10.60600/YU/VUH8KD) , file
42312 (`GerberGreenBook_Chapter3_Table_3_5`). Built by
`data-raw/book_tables.R`.
